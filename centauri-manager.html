    SDCP API Reference

    Reverse-engineered WebSocket commands for the Elegoo SDCP Protocol.

    • CMD 0 Telemetry
      Real-time machine status (Temperatures, fan speeds, XYZ coordinates, print progress). Sent asynchronously during print.
    • CMD 1 Attributes
      Static machine properties (Brand, Model, IP, MAC, Firmware version, Build volume, Free memory).
    • CMD 134 Heartbeat / Ping
      Used to keep the WebSocket connection alive and synchronize internal timers.
    • CMD 258 Get File List
      Retrieves an array of GCODE files from a specified path. Payload requires { "Url": "/local" }.
    • CMD 259 Delete File
      Deletes local file(s). Payload requires { "FileList": ["/local/file.gcode"] }.
    • CMD 320 Get History IDs
      Requests an array of unique UUIDs for all saved print history records.
    • CMD 321 Get History Details
      Fetches metadata for specific history IDs (Print time, Thumbnail URL, Timelapse status). Payload: { "Id": ["uuid"] }.
    • CMD 322 Delete History
      Removes history log, thumbnail, and associated timelapse video. Payload: { "Id": ["uuid"] }.
    • CMD 323 Unlock Video for Download
      Prepares a timelapse MP4 for HTTP transfer by releasing file locks. Payload: { "Url": ["/local/video.mp4"] }.
    • CMD 386 Live Camera Stream
      Toggles the MJPEG camera stream on port 3031. Payload: { "Enable": 1 } to start, 0 to stop.
